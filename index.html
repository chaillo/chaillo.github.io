我是谁

我是一名编程初学者，在学校里做了这个手语识别的课程项目。做这个项目之前，我对 AI 和深度学习几乎一无所知，只会写一些简单的 Python 代码。

为什么做这个项目

聋哑人在和普通人沟通时很不方便——大多数人看不懂手语，而专业翻译成本高、不随时可用。如果电脑能实时"看懂"手语并翻译成文字，这个问题就能部分解决，这让我觉得这个方向很有意义。

我也想通过这个项目真正搞懂"AI 是怎么工作的"——不是背概念，而是自己动手做一个能跑起来的东西，从零开始理解深度学习的全流程。

最大的收获：从安装 Python、配环境、排版本冲突报错，到最后看到摄像头认出"你好"两个字——这个过程让我真正明白了深度学习不是魔法，就是让电脑通过大量例子自己学规律。

🖐 手部关键点检测

用 Google MediaPipe Hands 检测 21 个手部关键点（手腕、关节、指尖），坐标归一化处理后作为识别输入，支持同时检测双手。

🧠 深度学习分类

四层全连接神经网络（63→512→256→128→类别数），含 BatchNorm 和 Dropout，用 TensorFlow 训练，支持用户自己录样本再训练。

😊 面部表情识别

MediaPipe Face Mesh 检测 468 个面部点，计算嘴巴开合比、眉眼距比，推断中性 / 惊讶 / 皱眉 / 说话中等表情。

📍 手部位置判断

MediaPipe Pose 检测肩膀和髋部坐标，划定身体各区域边界，判断手腕在头部 / 胸部 / 腹部等哪个区域。

📝 句子组合

手势稳定 0.35 秒触发一词，词语按时间顺序拼成句子，1 秒无手势自动换句，支持撤销、提交、查看历史。

🖥 可视化界面

Tkinter 桌面 GUI，含首页 / 实时识别 / 采集数据 / 训练模型 / 手势管理五个页面，支持导入 JSON/ZIP 手势数据包。
